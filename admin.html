Panduan Integrasi Server Hostinger

Website ini dikonfigurasi untuk menyimpan data ke file JSON lokal secara otomatis apabila dideploy ke server PHP Anda. Berikut adalah detail folder data Anda:

  • File data berita disimpan di: data/news.json
  • File data prestasi disimpan di: data/prestasi.json
  • Pastikan izin folder (CHMOD) untuk folder data/ diatur ke 0755 atau 0777 di File Manager Hostinger agar server bisa menulis berkas.

Mengubah Kata Sandi Admin

Demi keamanan, Anda disarankan mengubah kata sandi default (admin123) di server Hostinger Anda dengan cara:

  1. Buka File Manager di Hostinger hPanel.
  2. Di dalam folder admin/, buatlah berkas baru bernama config.php.
  3. Tuliskan isi berkas config.php sebagai berikut:
<?php
// Ganti 'katasandibaru' dengan kata sandi yang Anda inginkan
$password = 'katasandibaru';
?>

Setelah file tersebut disimpan, kata sandi login Anda akan otomatis berubah sesuai konfigurasi di file tersebut.
